# 生活中心诊断

> 你以什么为中心，就以什么为安全感、指引、智慧和力量的来源。
> 改变中心，才能改变一切观念。
>
> —— 改写自原著 p117

---

## 何时使用

- 用户即将或正在写 / 重写 **个人使命宣言**
- 用户说"我不知道自己到底想要什么"、"我总是做选择就后悔"
- 用户**反复**为同一类事情痛苦：配偶一变心自己就崩塌 / 失业就一无是处 / 被朋友疏远就自我怀疑 / 父母不认可就停摆
- 用户问"我活着是为了什么"、"什么对我才是最重要的"
- 用户在重大抉择前（辞职、结婚、搬迁、创业），想确认这个决定是不是"原则驱动"的

**在调用 `personal-mission-statement` 之前，几乎总是先跑这个。** 不先知道自己现在由什么锚定，就不知道要挪向何处。

## 核心概念：生活中心 = 四类需求的来源

柯维认为每个人都在寻找四样东西：

| 需求 | 含义 |
|---|---|
| **安全感** | 你的价值感、身份、根基、自尊 |
| **人生指引** | 决策的方向与标准 |
| **智慧** | 对生活的平衡感、判断力、整体理解 |
| **力量** | 行动、完成、选择、突破惯性的能力 |

这四样东西，你是从哪里获取的？**答案就是你的"生活中心"。**
只要生活中心出问题，这四样东西就会同时摇摆。

## 十种典型生活中心（附录一全本）

| 中心 | 当这个中心被动摇时，人会怎样 | 它在日常的常见信号 |
|---|---|---|
| **配偶中心** | 伴侣一冷淡/变心 → 安全感全塌，自我价值归零 | 对方心情左右自己一整天；分手后觉得"我这个人不存在了" |
| **家庭中心** | 家庭的评价/声誉/团结 = 行动标准 | "我爸妈会怎么看""不能给家里丢脸"凌驾于个人真实意愿 |
| **金钱中心** | 存款/收入的数字决定状态 | 涨薪一喜，跌股一愁；评估人先看对方收入；工作=赚钱工具 |
| **工作中心** | 身份 = 职位；失业/离职 = 身份崩塌 | 周末也脱不开；家庭"助力/阻力"工作；退休恐惧 |
| **财富中心** | 以占有量/显摆为身份 | 别人买什么我必须有；把人分"有用的/没用的" |
| **享乐中心** | 快乐体验成驱动；无聊是主要敌人 | 关系=一起玩的伙伴；长期计划没耐心做；回避所有不适 |
| **朋友中心** | 以"被接纳/受欢迎"为存在依据 | 被排斥即崩塌；跟风；害怕表达异见 |
| **敌人中心** | 由某个敌意对象反向定义自己 | 所有行动都在"反对 / 证明他错 / 报复"；敌人消失反而空虚 |
| **宗教中心** | 以教义组织为最高裁决 | 不合教义的人/事都是错的；形象大于实质；排斥"外人" |
| **自我中心** | "我"是唯一参考点 | 别人只是工具或陪衬；无法真正共情；长期孤立 |

以上十种都不稳定——**因为它们本身就是变动的**：伴侣会变心，家庭会分离，钱会贬值，工作会失业，财富有波动，享乐会疲劳，朋友会离散，敌人会消失或变质，宗教机构内部也有纷争，自我会老会病。

## 第十一种：原则中心（唯一健康的根基）

> "原则不会随环境、心情或他人态度改变。
> 它是永恒的自然法则，一旦违反必受惩罚；得到遵守时，则能维护尊严，从而实现真正的成长和幸福。"
> —— 原著附录一

**原则中心的人怎样看待同样的生活领域？**

| 领域 | 原则中心的视角 |
|---|---|
| 配偶 | 互利互赖关系中的**平等伙伴**，不是自我价值来源 |
| 家庭 | **改写几代人行为模式、变革的机会**——家是责任，不是身份 |
| 金钱 | **获取经济资源的手段**，与生活中的要务和价值观均衡 |
| 工作 | **运用才华、服务、贡献**的机会，不是身份本身 |
| 财富 | **可供利用的资源**，不是炫耀对象 |
| 享乐 | 目标明确的生活中**几乎所有活动产生的乐趣** |
| 朋友 | **相互依赖生活中的同伴、知心人**，不是受欢迎的证据 |
| 敌人 | **没有真正意义上的敌人**，只是思维定式不同，应予以理解和关心 |
| 宗教 | **真正原则的载体，服务和贡献的机会**——不是用来划分阵营的旗帜 |
| 自我 | **诸多独特、有才华、富有创造力的个体当中的一个**——而不是宇宙中心 |

## 诊断流程（对话驱动）

以下 4 步对话流程，作为 Claude 在此 skill 被触发后的默认展开。

### 第一步：描绘场景
让用户讲 1-2 个**最近让自己痛苦或卡住的具体情境**——不要让他概括"我对生活不满意"这种抽象结论。真相藏在具体里。

### 第二步：中心识别（4 组问题）
用下面四组问题，一组一组来（不要一次全抛出）：

**Q1 — 安全感问题：**
- "当昨晚/昨天你最难受的时候，你怎么让自己稳下来的？是想到什么/谁？"
- "如果今天突然 [配偶离开/失业/存款清零/被朋友圈孤立]，你觉得自己还剩下什么？"

**Q2 — 指引问题：**
- "上次做一个重要决定（辞职/搬家/分手/不分手），你最后的那个'拍板理由'是什么？"
- "这个'拍板理由'如果被挑战，你会怎样说服自己对方是错的？"

**Q3 — 智慧问题：**
- "当两个价值冲突（工作/家庭、省钱/健康、讨好/真实），你最后倾向哪边？为什么？"
- "你会对谁/什么报以'绝对信任'——即使它让你不舒服？"

**Q4 — 力量问题：**
- "上次你**没做**一件你明明应该做的事，是什么让你退缩了？"
- "上次你**做了**一件让自己骄傲的事，力量从哪来的？"

### 第三步：画出"中心分布图"

中心往往不是单一的，是 2-3 种混合，并且不同人生领域的中心可能不同（工作上金钱中心、感情上配偶中心、独处时享乐中心）。

| 你的主中心 | 占比估算 | 在哪些情境最明显 | 它的典型副作用 |
|---|---|---|---|
| [中心 1] | 40% | [情境] | [用户自述的痛点] |
| [中心 2] | 30% | [情境] | [痛点] |
| ... | ... | ... | ... |

> 不要急着贴"你是 X 中心的人"这种标签。中心是**行为模式**，不是人格分类。人会混合、也会随处境切换。

### 第四步：原则中心的替代视角

对用户主导的 2-3 个中心，逐一给出"如果以原则为中心，同样这件事会怎么看"：

| 你现在看 | 原则中心的视角 |
|---|---|
| "他不理我，我一整天都废了" | 他的心情是他的，我的行动由我的价值观决定 |
| "这个项目没做成，我这个人就完了" | 这个项目是贡献的一种形式，不是我这个人 |
| "父母不同意，我就不能" | 我尊重他们的立场，也承担自己选择的后果 |

然后**留一个悬而未决的问题给用户**：
> "如果下次 [类似情境] 再发生，你愿意试一次从原则中心看一下吗？哪怕只试一次？"

## 输出模板（深度分析模式）

用户说"帮我做生活中心诊断"时，按这个结构出一份：

```markdown
## 生活中心诊断

### 诊断对话摘要
[用户讲过的 2-3 个情境]

### 四项需求的来源分析

| 需求 | 你目前的来源 | 它稳定吗 |
|---|---|---|
| 安全感 | [用户自述锚点] | [稳/不稳+原因] |
| 指引 | [决策依据] | [稳/不稳] |
| 智慧 | [平衡感来源] | [稳/不稳] |
| 力量 | [行动动力来源] | [稳/不稳] |

### 主导中心识别

**主中心（占比 ~X%）：[中心名]**
- 证据：[来自对话]
- 副作用：[痛点]

**次中心（~Y%）：[中心名]**
- 证据 / 副作用

**情境性中心：** 工作时偏 [X]，独处时偏 [Y]

### 如果改以原则为中心

| 你目前的内心对话 | 原则中心的版本 |
|---|---|
| "[自述]" | "[重构]" |

### 向原则中心迁移的三个小实验（本周）

1. [具体场景，尝试从原则角度看一次]
2. [一个具体的"拒绝副作用"的小选择]
3. [一次跟原则核对的反思写作，10 分钟]

### 衔接建议

完成这次诊断之后，建议在**写/改人生宣言**之前，先带着这张图谈一下：
- 你希望 1 年后，主导中心变成什么？
- 如果要从 [当前主中心] 向原则中心迁移，首先要放下的是什么？

—— 然后调用 `personal-mission-statement` 深度展开。
```

## 约束条件

1. **中心不是人格标签** — 不要定性"你是自我中心的人"，只说"在这件事上你的锚定落在自我中心"
2. **十种中心无高低，只有稳定不稳定** — 配偶/家庭/宗教都是珍贵的生活内容，问题不在"爱配偶"，而在"把整个自我价值寄存在配偶身上"
3. **原则中心不是宗教性的** — 原则是诚信、公平、勤奋、服务、尊重等普世价值，不等于任何特定信仰
4. **迁移需要时间** — 用户今天发现自己是金钱中心，不等于明天就是原则中心。一次对话的目标是**看见**，不是**改完**
5. **不要让诊断变批评** — "原来你是享乐中心的人"说出口就伤人。用"在这件事上""这段时间"这类情境化表述

## 与其他技能的关联

- **前置于** `personal-mission-statement`：没诊断过中心的使命宣言，往往是现有中心的美化版
- **与** `circle-of-influence` **互补**：影响圈解决"能不能做"，生活中心解决"该不该做"
- **调用触发后置于** `stephen-covey` 的快诊断：总控在决定要不要进这个 skill 时，会先判断用户是不是"已有现有使命/目标体系，只是要 review"，还是"从根子上价值观漂移"。后者才走这个 skill

## 付诸行动（作业）

如果用户希望自己在会话之外继续做功课，留这张作业表：

1. **写下**：过去 12 个月里，让我**最痛苦**的 3 件事，一句话描述。
2. **在每一条后面回答**：这件事让我痛苦，是因为它动摇了我哪一项"来源"？（安全感 / 指引 / 智慧 / 力量）
3. **再写**：让我**最骄傲**的 3 件事。它们的力量来自哪？
4. **对照** 以上两张清单，自问：如果把所有这些"来源"换成原则（诚信、贡献、成长、公平、服务），哪些痛苦会自动减轻？哪些骄傲仍然成立？
5. **带着这份清单** 回来做人生宣言。

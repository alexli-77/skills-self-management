# 双赢协议

构建以互利为基础的协议结构，寻求双方都能真心投入的结果，
而非双方都有所失去的妥协。

---

## 何时使用

- 谈判、冲突解决或协议结构设计
- 双方似乎利益对立
- 用户问"我们怎样才能都得到想要的？"、"如何谈判"、"创建双赢"
- 委托、资源分配、角色边界讨论
- 当前的解决方式感觉是赢-输或输-赢

---

## 核心框架

双赢不是一种技巧；它是人际互动的整体哲学。
它来自于诚信品格、成熟度和富足心态。它在高信任关系中生长。

### 六种人际交往范式

| 范式 | 描述 | 长期结果 |
|------|------|---------|
| **赢-赢** | 双方都寻求互利 | 关系增强；持续合作 |
| **赢-输** | 我赢你输（竞争/操控） | 关系受损；对方寻找报复 |
| **输-赢** | 我让步你赢（讨好/放弃） | 自我尊重丧失；积怨积累 |
| **输-输** | 双方都损失（妥协/复仇） | 双方都不满意 |
| **赢** | 只关注自己得到什么 | 无视关系代价 |
| **赢-赢或不成交** | 互利或放弃 | 保留双方尊严；保持真诚 |

### 双赢的三个基础

1. **品格** — 诚信（言行一致）、成熟度（勇气 + 体谅）、富足心态（资源足够分享）
2. **关系** — 高情感账户余额；低信任使双赢几乎不可能
3. **协议** — 双赢协议的五个要素（见下方）

### 双赢协议的五个要素

| 要素 | 内容 |
|------|------|
| **期望结果** | 双方都想要什么成果？ |
| **准则** | 参数、原则和政策 |
| **资源** | 可用的支持（人力、财务、技术） |
| **问责制** | 绩效标准和评估 |
| **后果** | 实现或未实现结果的自然结果 |

---

## 执行流程

**第一步：范式诊断**
识别目前的互动范式：
- 是否有人在以赢-输思维运作？
- 是否有人因害怕冲突而输-赢？
- 双方都带着富足心态还是稀缺心态？

**第二步：双方利益理解**
在提出任何解决方案之前，深入理解双方真正需要什么：
- 不只是各方的立场（他们说他们想要什么）
- 而是他们的利益（他们为何想要它）
- 什么是必须有的？什么是最好有的？

**第三步：寻找第三方案**
不是我的方式，也不是你的方式，而是更好的方式：
- 解决双方真正的利益是否有创造性的解决方案？
- 能否创造原本不存在的价值？
- 是否有一个双方都能真心投入的方案？

**第四步：构建协议**
按照五个要素构建清晰的协议：
- 期望结果写得具体且双方认可
- 准则明确，避免未来的误解
- 资源承诺到位，不是空头支票
- 问责制结构明确，不模糊
- 后果自然且合理，非惩罚性

**第五步：双赢测试**
在最终确定之前：
- 双方是否都能真心投入这个协议？
- 这是否建立了关系？
- 如果不行，不成交是否比勉强同意更好？

## 约束条件

- 双赢需要品格，不只是技巧
- 如果信任度低，可能需要先建立情感账户
- 有些情况确实是赢-输（竞争）——不要强行双赢
- 「双赢或不成交」永远是一个选项——坏协议对任何人都没好处
- 妥协不是双赢——双方都放弃一些是输-输
- 另一方也必须想要双赢；你无法强迫它

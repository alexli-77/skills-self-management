# 双赢协议 · 第三条路

> "双赢者把生活看作一个**合作的舞台**，而不是一个角斗场。
> 一般人看事情多用二分法——不是强就是弱，不是胜就是败。
> 其实世界之大，绝非非此即彼。"
> —— 原著 p223

---

## 何时使用

- 谈判、冲突解决、协议结构设计
- 双方看起来利益对立（薪资、职责、分工、合同、家庭资源分配）
- 用户问"我们怎样才能都得到想要的？"、"他占便宜我就输吗？"、"怎样才能不伤关系又争到我要的？"
- 委托、资源分配、角色边界、家规制定
- 准备进入一次"零和看起来不可避免"的谈判

## 核心框架

### 六种人际交往范式（原著 p225-230）

| 范式 | 描述 | 长期结果 |
|---|---|---|
| **利人利己（Win-Win）** | 双方都赢 | 关系增强；长期合作 |
| **损人利己（Win-Lose）** | 我赢你输（竞争/操控） | 关系受损；对方蓄力报复 |
| **损己利人（Lose-Win）** | 我让你赢（讨好/放弃） | 自尊丧失；怨气积累；最后总爆发 |
| **两败俱伤（Lose-Lose）** | 双方都输（报复/死磕） | 两败俱伤；关系彻底坏 |
| **独善其身（Win）** | 只管自己赢，不关心对方 | 忽视关系代价；看似高效但走不远 |
| **好聚好散（Win-Win or No Deal）** | 双赢或不合作 | 保留双方尊严；不强行妥协 |

**核心诊断问题：** "你现在的互动，是上述六种中哪一种？你**希望**它是哪一种？"

### "好聚好散"是最被低估的选项（原著 p228）

> "如果找不到双赢方案，干脆好聚好散——以后再合作。
> 有这个选项的存在，本身就是从容的来源：
> 你不再需要为了留住这单生意而接受损己利人的条件，
> 也不再需要为了怕对方走而变成损人利己的人。"

**"不成交"不是失败——它是**守住双方品格**的最后保险。**

### 为什么不能是"妥协"？

妥协 = 各让一步 = 1+1=1.5
双赢 ≠ 妥协。双赢追求 1+1=3，这叫**统合综效**（Synergy）。

> "妥协是你砍一刀，我砍一刀，谁都不满意但大家都累了。
> 统合综效是两人一起找到一条**原来都没看到**的路。"

### 双赢的三个地基（原著 p232）

1. **品格（Character）**
   - **诚信**：言行一致，不耍手段
   - **成熟度**：勇气 + 体谅的平衡
     - 只有勇气没体谅 = 损人利己
     - 只有体谅没勇气 = 损己利人
     - 勇气 + 体谅 = 双赢
   - **富足心态**：相信"蛋糕可以做大"；对应相反是"稀缺心态"——认为资源是固定的零和

2. **关系（Relationship）**
   - 没有情感账户余额，双赢几乎不可能
   - 透支的关系里谈双赢，对方会解读为新的操控
   - 所以：**关系透支时，先调用 `emotional-bank-account` 存款，再谈协议**

3. **协议（Agreement）** —— 见下面五要素

---

### 双赢协议的五要素（原著 p243-246）

| 要素 | 内容 | 常见漏洞 |
|---|---|---|
| **1. 预期结果** | 具体、可衡量地说清双方要达成什么 | 停留在"努力配合""尽力"这类模糊词 |
| **2. 指导方针** | 过程中的规则、原则、边界、不能做的事 | 只讲结果不讲过程，后期为"方法"扯皮 |
| **3. 可用资源** | 人员、预算、工具、信息、联系人、时间 | 承诺资源但不到位，或对方以为资源包含所有 |
| **4. 任务考核** | 如何追踪、谁来评估、多频繁 | 缺乏可见度，等问题爆发才知道 |
| **5. 奖惩制度** | 成功/不成功的自然后果（非惩罚性） | 没说清后果，或只说惩罚不说奖励 |

**这五要素写得清的协议，执行时冲突减少 80%。** 大多数后期冲突，不是立场对立，是这五项中某一项没写清。

### 第三条路：统合综效（原著 p283-305）

> "统合综效的基本心态是：
> 如果一位具有相当聪明才智的人跟我意见不同，那么对方的主张必有我尚未体会的奥妙，值得加以了解。"
> —— 原著 p283

**三种沟通层次（对应双赢的进阶）：**

| 层次 | 沟通方式 | 信任 | 结果 |
|---|---|---|---|
| **互相提防** | 猜忌 / 防卫 / 输赢思维 | 低 | 损人利己 / 损己利人 |
| **互相尊重** | 礼貌 / 妥协 | 中 | 中庸的妥协（1+1=1.5） |
| **统合综效** | 创造性协作 / 差异即财富 | 高 | 第三条路（1+1=3+） |

**统合综效的前提：**
- 双方都放下了"只能我对或只能他对"的二分法
- 有足够的信任承受"我不知道答案是什么"的不确定
- 有真诚的好奇："对方看到了我没看到的什么？"

## 执行流程

### 第一步：范式诊断

让用户明示：
- "你现在和对方的互动，是六种里哪一种？"
- "对方在哪一种？"
- "如果今天什么都不做，三个月后这段互动会变成哪种？"

常见情况：
- **你在损己利人，对方在独善其身** → 你一直在给，对方理所当然。需要停下来做品格诊断
- **双方都在损人利己** → 纯粹零和竞争，先看"好聚好散"是否更好
- **你在双赢，对方在损人利己** → 你需要装备"好聚好散"作为底牌，否则单方面的双赢会被吃干

### 第二步：理解双方的**利益**（而非立场）

**立场 vs 利益** 是谈判最重要的区分：
- **立场（Position）：** 对方口头要什么（"我要加薪 30%")
- **利益（Interest）：** 对方为什么要（安全感？感觉被重视？对比公平？家里经济压力？）

**双赢几乎永远发生在"利益层面"——立场层面大多数是零和。**

操作：
1. 列出你自己的 **必须项 + 最好项**（区分）
2. 列出对方的 **必须项 + 最好项**（同理，先猜再验证）
3. 看两方的"必须项"是否真的冲突——通常没那么冲突；看起来冲突的是"最好项"

### 第三步：寻找第三条路

用这组问题打开可能性：
- 能不能**把蛋糕做大**而不是切分？
- 能不能**换一种交换方式**（不是钱换时间，是信任换自由度）？
- 能不能**引入时间维度**（现在让一步换未来的复利）？
- 对方**真正在意的是**什么（过程 / 关系 / 面子 / 里子）？我能在他最在意的那件事上让利，他能在我最在意的那件事上让利吗？

### 第四步：起草五要素协议

```
预期结果：___（具体、可衡量、有时间）
指导方针：___（过程中不能做、必须做的）
可用资源：___（双方分别投入什么）
任务考核：___（谁怎么追，多频繁）
奖惩制度：___（成功/失败的自然后果）
```

写完之后**读一遍**，问：
- 读完我是不是清晰知道下一步做什么？
- 对方读完会不会有歧义？
- 三个月后如果出问题，这份协议能帮我们回到正轨吗？

### 第五步：双赢检验

| 检验问题 | 答案 |
|---|---|
| 我是**真心**能投入这份协议吗？ | 是 / 否 |
| 对方是**真心**能投入的吗？ | 是 / 否 |
| 这份协议**增强**了关系还是削弱了？ | 增强 / 削弱 |
| 如果三个月后我后悔，**哪一条**会让我后悔？ | ___ |

**任何一个"否"或"削弱"出现——都该回到第三步或考虑"好聚好散"。**

### 第六步：底牌——"好聚好散"

正式进入谈判前，**心里先设好这条底线**：

- 我绝对不接受的条件是：___
- 到了这个条件，我选择"不合作"
- 不合作不是报复——我礼貌、尊重地离开，保留关系的未来可能

**这条底牌的存在，让你在谈判里不会被恐惧驱动。**

## 原著经典案例

**父子游戏机（原著 p228）：**
父亲不想让儿子买游戏机，儿子想要。
- 损人利己：爸说"不准买"，儿子偷偷存钱
- 损己利人：爸屈服，儿子一天到晚玩
- 妥协：买便宜的，父子都不满意
- **双赢：**
  - 爸的利益：怕儿子沉迷、影响学习
  - 儿子的利益：想和同学玩、想拥有"大人允许的东西"
  - **第三条路**：约定每周时间、完成学业的前提下允许；共同出资；一起选一款"玩得久"的
  - 不只是给了游戏机，还给了儿子"如何管理自己"的训练

**商业合同的 Win-Win or No Deal（原著 p229）：**
柯维的公司曾与一家银行谈培训合作。对方要求定制到非常细节的程度，成本远超报价。柯维团队内部讨论后决定："这个单不接"，坦诚说明。**出乎意料**——三个月后对方回来，以原价接受原方案，并说："我们就是想看看你们有没有底线。有底线的供应商才值得合作。"
**教训：** "好聚好散"的底气，反而赢得长期业务。

## 约束条件

1. **双赢需要品格，不只是技巧** —— 没品格的双赢谈判只是更复杂的操控
2. **信任不足时先建账户** —— 情感账户透支时，直接谈协议都是空的
3. **不是所有场景都适合双赢** —— 单次博弈、对方恶意、涉及底线原则时，不要强行双赢
4. **"双赢或不成交"永远是选项** —— 坏协议对任何人都没好处
5. **妥协不是双赢，是两败俱伤的温柔版** —— 写完协议前先问自己"是妥协还是综效"
6. **对方也必须想要双赢** —— 你无法强迫单方面的"你想双赢他想损人"——此时你的底牌就是"不合作"

## 与其他技能的关联

- 前置 `emotional-bank-account`：账户透支的关系里，双赢谈不拢
- 前置 `seek-first-to-understand`：不先理解对方利益，你以为的"双赢方案"对他来说还是零和
- 后接 `circle-of-influence`：如果对方拒绝合作双赢，你影响圈内能做的是什么？保持自己的品格、等机会

## 付诸行动（作业）

### 本周做一次"范式审计"

1. 列出你目前生活中**最紧张的三段关系或谈判**（配偶/上下级/合作方/父母）
2. 给每一段**命名一个范式**（损人利己？损己利人？双赢？…）
3. 对每一段问：
   - 我最想它成为哪一种？
   - 距离那个目标，我下周能走的**一小步**是什么？
   - 如果走不通，我的"好聚好散"底牌是什么？

### 一次真实的双赢草案

选一个**具体**正在发生的谈判/协议（加薪、职责分工、家务分工、合同条款），用上面的五要素模板起草一份。然后带进真实对话试试——不要期待一次就谈成，只期待第一次比上次进步一点。

> "差异不是分歧的理由，是综效的起点。"

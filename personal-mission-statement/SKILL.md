# 个人使命宣言 · 以终为始

> "所有事物都经过两次的创造——先是在脑海里酝酿，其次才是实质的创造。"
> —— 原著 p110

个人使命宣言是你**第一次创造**的具象表达——你先在心里想清楚自己要成为什么样的人、要过什么样的生活，然后现实才能一步步逼近它。
柯维称写使命宣言是"**你一生中可能最重要的一件事**"——它成为你所有决策的衡量标准。

---

## 何时使用

- 用户对人生方向、目标或价值观感到迷茫
- 面临重大人生决策（辞职、转行、结婚、移居）却缺乏判断标准
- 感到与最重要的事"断线"，每天像在完成任务
- 用户问"帮我写使命宣言"、"我的人生使命是什么"
- 进入新阶段（入职、毕业、为人父母、退休）
- 已经有过宣言，要做年/季度的审视与重写

---

## 前置动作（强烈建议）：先做生活中心诊断

柯维在第四章花了大量篇幅讲**生活中心决定思维定式，思维定式决定人生宣言的底色**。跳过这一步直接写宣言，往往写出来的是：

- 配偶中心的人：宣言围着"经营好这段关系"打转
- 工作中心的人：宣言以职业成就为核心
- 金钱中心的人：宣言是"财富自由"的变体
- 家庭中心的人：宣言写成"为家庭奉献"

这些不是错的，但都**依赖于外部变量**。一旦对象变了（伴侣离开、行业崩塌、家人离世），整个宣言失效。

所以推荐：**先调用 `life-center-diagnosis`，看清当下的生活中心，再带着这份诊断进来写宣言。**

## 核心框架

### 两次创造

所有事物都经历两次创造：
- **第一次创造：心理层面（Mental Creation）** —— 想清楚、设计好
- **第二次创造：实体层面（Physical Creation）** —— 执行、实现

你在**哪次创造**里缺席，你就会在那里被别人或惯性代替。
- 不主动做第一次创造 → 社会、家庭、广告、算法给你写了剧本
- 做了第一次但不执行第二次 → 沦为"想得多做得少"的人

**使命宣言 = 第一次创造的正式记录。**

### 四种基本需求（p116-117）

| 需求 | 层面 | 对应问题 |
|---|---|---|
| **生存（live）** | 身体 | 我需要什么维持健康与生计？ |
| **爱（love）** | 社会·情感 | 哪些人与关系对我至关重要？ |
| **学习（learn）** | 智力 | 我想如何成长？ |
| **留下（leave a legacy）** | 精神 | 我想为这个世界留下什么？ |

**以原则为中心的人**从四个层面平衡地回答这些问题；**以其他中心为锚的人**会把某一项过度放大，其他塌陷。

### 四种人类禀赋

写宣言需要同时调动：
1. **自我意识** — 能跳出自己观察自己
2. **良知** — 分辨是非对错的内在罗盘
3. **创造性想象** — 设想尚不存在的未来自我
4. **独立意志** — 不靠情绪推动，靠承诺推动的能力

写作过程遇到卡壳时，常常是某一项禀赋在打盹——可以点名唤醒它。

## 执行流程

### 第一步：遗产可视化（原著经典练习，p116）

> "想象你要去参加一个葬礼——结果发现躺在棺材里的是你自己。这是三年后你的葬礼。
> 你的亲人、朋友、同事、社区成员都在。你最希望他们每人上台说什么？"

**分四位讲者：**
- **家人：** 他/她最希望你记得哪些品格与相处时刻？（注意：不是"他很成功"，是"他陪我度过…"）
- **亲近朋友：** 他/她会怎样概括你这个人？
- **职业同行 / 合作伙伴：** 你留下了什么贡献、什么风格？
- **社区 / 更广的世界：** 你对一群陌生人做过什么？他们会怎么记得你？

把这四段话写下来。**这就是你的"终"——你内心真正向往的样子。**

### 第二步：角色识别

列出你在生活中扮演的 5-7 个核心角色（不是身份标签，是关系形态）：

| 角色 | 在这个角色里，我想成为怎样的人？ |
|---|---|
| 个体（身体、心智、灵魂） | … |
| 配偶 / 伴侣 | … |
| 父母 / 子女 | … |
| 专业身份（设计师/老师/创业者…） | … |
| 团队成员 / 管理者 | … |
| 朋友 | … |
| 社区 / 公民 | … |

**提示：** 一个人至少 5 个角色才算看清了生活。只列出"爸爸"和"设计师"，遗漏了"自己对自己的角色"或"朋友圈里的自己"，就是把生活简化了。

### 第三步：核心价值观厘清（不妥协原则）

用以下四问找出你的**不可妥协原则**：

1. "即使付出代价，我也会坚守什么？"
2. "违反什么原则，会让我看不起自己？"
3. "我钦佩的人身上，我最向往的是哪些品格？"
4. "回顾我这一生让我最骄傲的 3 个时刻，它们共同体现了什么？"

常见原则领域：**诚信、勇气、同理、卓越、服务、成长、公正、忠诚、创造、信仰、节制、克制、坚韧。**

从中挑出 3-5 个**你愿意写进墓志铭**的。

### 第四步：独特贡献识别

问：
- 我有哪些独特的才能 / 视角 / 经历？
- 世界上我感到**有责任**（而不是有义务）去做的事是什么？
- 如果知道一定不会失败，我会去做什么？
- 如果 10 年后回看，**最让我后悔没做**的事是什么？

这些回答指向你的"贡献主题"——使命宣言里的动词部分。

### 第五步：起草宣言

把前四步整合成 1-3 段文字：

- **第一段（"是谁" — 品格）：** 我想以什么样的人活着
- **第二段（"做什么" — 贡献）：** 我要用这一生的精力投向哪里
- **第三段（"怎么做" — 原则）：** 我愿意以什么原则作为每一个选择的衡量标准

**写作约束：**
- 用第一人称
- 用肯定句（"我是 / 我做 / 我坚持"，不写"我不…"）
- 用现在时态（仿佛已经是真的，不是"将要")
- 以品格为锚，不以成就为锚
- 既要宽到涵盖所有角色，也要具体到能指导决策

### 第六步：决策测试

让宣言"活起来"，用它测试当前面前 2-3 个具体决策：
- 这份宣言能帮你对"该接这个项目吗？"说是或不？
- 能帮你决定"该怎么过这个周末"？
- 能帮你决定"什么时候该拒绝父母的安排"？

**如果宣言在真实决策面前"帮不上忙"，说明它太抽象——回去改。**

### 第七步：时间维度

- **每周**：周日花 5 分钟重读一次，作为 Q2 规划的锚
- **每季**：对照这三个月的重大决策，有没有偏离？
- **每年**：完整重写一次——人会成长，宣言不是写完就刻在石头上的
- **人生阶段转换**：毕业、结婚、为人父母、退休，每次都值得从头再写

## 常见陷阱

1. **把宣言写成 KPI 集合**（"我要在 40 岁前财务自由 / 发表 10 篇论文"）——这是目标，不是使命
2. **复制别人的宣言**（乔布斯、稻盛和夫的话）——宣言必须是**你的**，不是借来的
3. **过于抽象**（"做最好的自己""活出价值"）——抽象到没法判断任何具体决策
4. **忽略"私下的你"**——只写职业 / 家庭角色，漏掉"独处的你"是谁
5. **一次定终身**——宣言不是墓碑，是活的契约；人变了它就要变

---

## 约束条件

1. **深度反思无法仓促——通常需要数周至数月**
2. **品格在前，贡献在后，技巧在更后**——由内而外
3. **原则先于目标，目标先于计划**——不要跳过任何一层
4. **宣言要比目标活得久得多**——目标会换，原则不换
5. **不代替用户写**——Claude 可以提问、整理、反射，但每个字必须由用户自己说出来

## 付诸行动（作业）

**起步三问（本周完成）：**

1. 写下你最钦佩的一个（活着或去世的）真实人物。在他/她身上，你最想拥有的是哪 3 个品格？
2. 想象你 3 年后的葬礼。你最希望**你妈妈 / 伴侣 / 孩子 / 10 年前的自己**中的一个说的一段话是什么？把它写下来。
3. 选一个你最近做得不满意的小决定（加班到几点？和谁吃饭？说了什么话？）—— 如果你已有宣言，它会怎样建议你换种选法？

这三题答完，你已经有了使命宣言的**种子**。剩下的，是让它长大。

> "若你不能清楚描绘自己想成为什么，生活就会替你做这个决定——
> 而生活的默认答案，常常不是你想要的那一个。"
